🔂 Copy Multi-Scan Results

Copy all scan results including numbered instances to a specified directory

💡 Copy Instructions

1️⃣ Get Destination Path

Run this command in your target directory in Kali:
pwd

2️⃣ What Gets Copied

  • All numbered scan instances (HTTPx_1, HTTPx_2, etc.)
  • Individual scan output files with timestamps
  • Project configuration and target lists
  • Live scan outputs organized by type and number
  • Complete scan history - nothing is lost

3️⃣ Example Paths

Kali: /home/username/project_folder/client_assessment
⚠️ Note: The copy operation preserves the complete multi-scan structure. Each scan type will have numbered instances maintaining the scan history.
